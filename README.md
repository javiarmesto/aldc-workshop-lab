# Directions EMEA 2026 · Spec-Driven AL Development
**Roberto Corella y Javier Armesto · 105 minutos · English**

45 minutos de explicación y demostración de ALDC, seguidos de **un único laboratorio de 60 minutos: Customer Review with History**.

## Empieza aquí
1. [Descarga el laboratorio v18 (ZIP)](https://directions-workshop.vercel.app/materials/Directions-Lab-60min-v18.zip).
2. Extrae todos los archivos en una carpeta local.
3. Abre `directions-60/directions.code-workspace` en VS Code.
4. Sigue `START-HERE.md` y la preparación previa incluidos en el ZIP antes del workshop.
5. Durante el laboratorio, sigue la guía del mismo paquete y registra tus resultados.

**No necesitas cuenta de GitHub, crear un repositorio ni clonar esta plantilla.** Utiliza el ZIP del portal como material de asistentes; no mezcles sus archivos con el starter de la raíz de este repositorio.
