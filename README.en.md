# Directions EMEA 2026 · Spec-Driven AL Development
**Roberto Corella and Javier Armesto · English · 105 minutes**

45 minutes explaining ALDC through a live case, followed by **one continuous 60-minute lab: Customer Review with History**.

## Start here
1. [Download the lab ZIP · v18](https://directions-workshop.vercel.app/materials/Directions-Lab-60min-v18.zip).
2. Extract all files into a local folder.
3. Open `directions-60/directions.code-workspace` in VS Code.
4. Follow the included `START-HERE.md` and preparation instructions before the workshop.
5. Follow the guide from that same package and record your actual results.

**No GitHub account, repository creation or cloning is required.** Use the portal ZIP as the participant package. Do not mix it with the root starter in this repository.
